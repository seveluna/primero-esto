# Guion de vídeo de demostración (máximo 5 minutos)

Graba la pantalla con una cuenta de prueba y datos ficticios. Oculta el correo personal y cualquier clave API. Exporta el vídeo y súbelo a la misma carpeta de Google Drive que los dos documentos.

| Tiempo | Qué mostrar | Qué contar |
| --- | --- | --- |
| 0:00–0:30 | Portada | Problema: alimentos olvidados y desperdicio. |
| 0:30–1:10 | Registro o inicio de sesión; «Datos de ejemplo» | La despensa se guarda y se sincroniza entre dispositivos. |
| 1:10–2:00 | Añadir y editar un alimento; fecha orientativa de fruta | Entrada manual fiable, categorías y fechas diferenciadas. |
| 2:00–2:45 | Marcar agotado; lista de la compra; reponer | Del frigo a la compra, sin perder el contexto. |
| 2:45–3:35 | Avisos y recetas automáticas; botón «Buscar recetas con mi despensa» | Dos formas de descubrir recetas y notificaciones opcionales. |
| 3:35–4:20 | Panel «Conectar mi IA», sin mostrar ni pegar una clave real | Cada usuario puede elegir proveedor; el catálogo funciona sin IA. |
| 4:20–4:45 | Repositorio y URL pública | Codex para desarrollar; Cloudflare Worker y D1 para ejecutar y guardar. |

Antes de enviar el formulario oficial, comprueba que la carpeta, ambos Google Docs y el vídeo estén configurados como «Cualquier persona con el enlace puede ver» y copia sus enlaces individuales. Las bases fijan el cierre el 19 de octubre de 2026 a las 23:59, hora peninsular española.
